# Resume Website

A responsive personal resume website built using HTML and CSS to showcase contact details, skills, education, work experience, and a brief about section.

## Features

- Clean, professional single-page layout
- Sections for Contact, Skills, Education, About, and Work Experience
- Responsive design
- Icons via Font Awesome

## Tech Stack

HTML5, CSS3, Font Awesome (CDN)

## Getting Started

No installation required.

```bash
git clone https://github.com/Akashi-01/Resume-Website.git
```

Open `index.html` in your browser to view the resume.
